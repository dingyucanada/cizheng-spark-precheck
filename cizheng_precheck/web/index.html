    把模型装进你的 Spark

    解压安装包，在项目目录运行：

    bash scripts/install-spark.sh --with-system-packages

    安装入口会下载 Qwen3-VL-8B-Instruct 多模态模型，启动 NVIDIA vLLM GPU 服务，执行真实照片探测，再启动工作台并生成验收报告。

    首次下载需要网络、Docker 使用权限及足够磁盘。模型和资料准备好后可以离线处理照片。其他 Spark 用户拿到同一安装包即可使用，无需你的云端账号或 API 密钥。

    详细步骤见安装包中的 START_HERE.md。若模型已经在运行，请检查 .env 中的服务地址和模型名，再点击“检查连接”。
