# 瓷证一页预检：可信处理架构

## 业务边界

服务于非专业持有人送交拍卖行或鉴定机构之前的一次预检。重点是发现值得核实的明显矛盾、修补或异常候选，把疑点定位到照片，减少空泛的“像真/像假”意见。输出是照片辅助意见，不签发实物真伪认证。

系统允许直接给出“优先送检”的意见，但不能把不完整图像证据变成真品概率。现阶段没有充分的专家真值和概率校准数据；Jev 或 Laya 的路由概率不能替代这些数据。

## 端、边、云的责任

| 部分 | 当前实现 | 数据边界 |
|---|---|---|
| 采集端 | 浏览器提交1–6图；可供手机、相机导入或 Jetson 客户端复用 HTTP 接口 | 照片按同一器物成组提交；来源和视角为上传者声明 |
| Spark | 原图留存、像素检查、视觉模型、索引检索、比较、引用校验、评分、PDF | 原图及用户说明保留在本机/显式私网视觉服务 |
| 公开资料服务 | 可选 The Met 及芝加哥艺术博物馆 API 检索，取得馆方记录及获准公开的参考图 | 只发送封闭词表中的器物检索词 |
| 云端文字审阅 | 可配置兼容接口；全局开关和单案许可同时开启 | 仅公开原文及引用条目，不发送图像、视觉观察或持有人说明；结果不提高评分 |
| BaaS / BI | 本版未引入 | 单机单机构不需要额外平台；规模化时再接账号、队列和运营统计 |

“离线”指已经准备好模型和资料后，案件处理可关闭联网。初次安装下载不属于离线阶段。Jetson 在这里可承担采集终端；本仓库没有把它包装成已验证的第二套推理硬件。

## 实际执行顺序

1. **入件**：输入限制、格式解码、重复图拦截、原文件SHA-256、解码像素指纹和基础画质信息。原图字节保存；模型读取去除EXIF的预览。当前检测不判AI生成图，不把图片清晰度当鉴定置信度。
2. **照片来源核验**：原文件哈希一致，或解码像素一致，可认定图片对应本地索引中的同一图像；感知哈希接近仅列为相似候选。来源索引当前为9张图，未命中不表示原图原创。任何命中都不确认另一件实物身份。
3. **视觉观察**：视觉模型先只接收输入图和编号，按schema生成观察、归一化区域、替代解释、视角覆盖、器物同一性。未提供馆藏标题或用户主张，避免以记忆的作品名称替代看图。
4. **资料检索**：小规模本地词项检索，加可选公开API。检索到的不同器型只作为背景资料，不参与直接归属反驳。返回资料原句、来源机构、URL、记录指纹及日期。参考图有许可和固定来源检查，只下载公开允许的图像。当前不声称已部署向量语义检索或互联网全库反向搜图。
5. **跨证据比较**：把待检照片、参考图、观察和原文同时提供给比较步骤，区分直接主张矛盾、风格差异、信息不足。参考图的细节不得变成待检图观察。
6. **代码核验**：照片ID和观察ID存在；引用ID来自本轮检索；引用原句实际存在于保存摘录。未知来源、伪造原句、悬空观察被剔除。
7. **模型理由复核**：检查摘录是否支持比较理由、是否忽略替代解释。当前是同一模型的分步复核，属于一致性检查，不构成独立专家意见。结果不靠“多模型投票”转为真品率。
8. **规则评分及一页报告**：规则版本固定；只显示已形成的证据支持程度。底足缺失、多件混入、严重质量不足时不评分。报告保留照片、意见、评分、三条理由、下一步；完整证据可展开和导出。

## 源头交叉核验

来源数量按**机构**去重，而不是网页数量。同一个博物馆的两条记录不是两个独立来源。当前随包资料包括The Met和芝加哥艺术博物馆的记录；来源机构不同也不等于器物归属已经被交叉证实。可使用 `scripts/import-source.py` 导入经人工核对的其他机构摘录，要求URL、页码/段落、权限、核对人员和日期；导入器按来源域名归并机构。

新参考资料仅作为比较对象，不能默认其特征为所有同代器物的必要条件。专业规则需要逐条界定适用器型、窑口、时段和反例。高仿风险不能由“与标准器不同”一条规则概括。

## 可靠性机制

- 后台持久化案件和任务；单次提交立即返回任务编号。前端轮询，不依赖长HTTP连接等待整篇报告。
- 单模型任务串行，队列有上限；模型调用最多一次格式修复，整件有总截止时间。
- 出错、取消、重启均有明确状态；不产生伪造的成功报告。原图保留，可重新运行。
- 发布PDF前重新核验原图哈希，原文件被改变即拒绝发布。
- 固定一页布局，文字必须落在容量内；超出时失败，不自动缩到不可读或静默删掉理由。
- 服务默认回环地址，远程访问要口令；POST校验会话和来源；不让浏览器设定模型URL或凭据。
- 模型、引用和用户说明均不用于执行命令；联网只调用固定馆藏服务和固定图片域名，禁止任意URL抓取。

## 不同结果类型

| 类型 | 形成方式 | 如何呈现 |
|---|---|---|
| 完整视觉预检 | 真实本地视觉请求、参考比对、引用及理由复核 | 本地视觉 · 辅助预检 |
| 公开馆藏资料核查 | 真正匹配输入图指纹，读取原始馆方记录，执行规则 | 公开馆藏 · 资料核查；明确本轮未运行视觉模型 |
| 无法完成 | 服务异常、无模型、格式不合格或任务超时 | 保留原图及阶段记录；没有伪装的报告 |
| 证据不足 | 运行完成，但证据不支持评分 | 正常报告，评分显示“暂不评分”，给出补证动作 |

## 后续提高效果的工作

优先收集器物级隔离的专家审阅集，覆盖高仿、普通现代器、真实修补和低质量照片。观察是否正确、引用是否相关、理由是否跳跃和送检建议是否有用分别评价。只有这些数据证实瓶颈后，才评估更大视觉模型、检索重排或领域LoRA。

后续可以加入相机标尺标定、Jetson采集盒、显微成像和检测报告接入。采集硬件本身不能将照片意见升级为物理测年结果。联邦训练和强化学习不在当前实现范围，不能以“越用越聪明”替代真实的标注、评测、发布和回滚流程。
