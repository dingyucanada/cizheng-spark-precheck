# 送检关注评分：规则版本 review-priority-1.1

这是一个**复核优先级**，不是模型自报置信度，不是“真品率”，也不是交易估值。分数由 `policy.py` 计算，模型不能直接填写最终分数。

## 视觉模式的条件

前置条件：至少两张不同照片；模型可见视角包括整体和底足；器物同一性为一致；识别为陶瓷；没有基础画质警示；至少有一条可读取的观察。条件不满足时暂不评分。

- **2分**：存在经过引用和模型复核的比较，本轮没有形成需优先复核的具体矛盾。仅有观察而没有可用比较依据，不给2分。
- **3分**：发现修补或异常候选。替代解释必须保留，修补不等于仿品。
- **4分**：至少一项与用户明确归属主张直接相关的矛盾，通过引用核验和模型二次复核。单纯相似/风格差异不触发。
- **5分**：满足4分，并且矛盾涉及至少两个观察维度、至少两个来源机构。仍然是优先送检，不是确认伪造。
- **1分**：本版不自动使用，避免造成“已确认真品、可以放心交易”的暗示。

若没有明确年代/窑口主张，不能用参考器的不同直接触发4或5分。各等级阈值尚未经过专家人群校准，因此报告明示为规则等级。

## 资料核查模式

全部输入图精确匹配同一馆藏时，依据资料核查规则给出2、3或4级送检关注程度，详见下文。分数不表示真伪，未运行视觉模型时不会声称模型观察到了某一细节。照片混入不同器物或匹配不完整仍暂不评分。

## 必须区分的事实

1. 文件一致 → 确认同一图片文件；不确认持有人有原作。
2. 引用原句存在 → 引用完整性通过；不自动证明推断成立。
3. 模型复核支持 → 第二次模型检查；不代表独立专家认定。
4. 无矛盾 → 本次范围内未形成矛盾；不代表真品。

## 专家验证表

对每一件样本收集：原始照片、可公开的专家基准、关键观察位置、允许的结论范围、误判反例和建议送检动作。按器物及来源拆分开发集和测试集；不得把同一件器物不同照片分到两边。建议分别评价观察正确率、引用相关性、理由支持性、过度判断比例和拒判/补证比例。

## v0.2 资料核查规则

同一来源的全部照片精确匹配时，资料可查且没有明确冲突记2级（常规核验）；有馆方修补记载记3级；体验中明确设定的明代说法直接冲突于对应馆方清代19世纪记载时记4级。第三条只适用于声明了体验设定、原句可核对且照片精确匹配的输入；不判断该馆藏为赝品。不同器物混图、不完整匹配仍不评分。真实视觉分析使用观察和引用复核规则，不按案例ID指定分数。
